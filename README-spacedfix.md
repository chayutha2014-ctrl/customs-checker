# แก้ตัวเลขที่ใช้ช่องว่างคั่นหลักพัน + ลบคีย์ซ้ำใน box cache

## สรุปการวินิจฉัย

ผลตรวจ invoice ที่ตกไป 4 ใบ ไม่ได้มีสาเหตุเดียว

| ไฟล์ | สาเหตุจริง |
|---|---|
| FUJIAN | คีย์ซ้ำใน `_box_cache.json` (`.jpeg` + `.png`) ตารางถูกนับสองรอบ |
| SHIJUN | `18 422.00` อ่านไม่ออก บรรทัดหลุด |
| VORETO, HUANYU | ยังไม่ยืนยัน ต้องวัดหลังติดตั้ง |

ข้อกล่าวหาที่พิสูจน์แล้วว่า **ไม่ใช่** สาเหตุ
- `numbers.py` เรื่องการตัดหน่วยท้ายตัวเลข — เปิด/ปิดบนกล่องชุดเดียวกันได้ผลเท่ากันเป๊ะ
- `merge_words()` ใน `build_boxes.py` — ทั้งสามไฟล์เป็นสแกน ไม่เคยผ่านฟังก์ชันนั้น

## SHIJUN

```
5 | Plastic Bottle 150g WEK | 30200 | 0.61 | 18 422.00
```

`_TOKEN` คว้าได้แค่ `18` แล้วคืน `18.0` ออกไปเหมือนเป็นจำนวนเงินเต็ม
บรรทัดเข้าคู่ไม่ได้จึงหลุด  190,028.50 − 18,422.00 = 171,606.50 ตรงกับที่เครื่องคำนวณได้

การคืน `18.0` อันตรายกว่าการคืน `None` เพราะเป็นตัวเลขที่ดูปกติแต่ผิด

## สิ่งที่แก้

`numbers.py` รวมตัวเลขที่ช่องว่างคั่นหลักพันกลับเป็นตัวเลขเดียว
บังคับให้กลุ่มหลังช่องว่างมี 3 หลักเป๊ะ `12 345` จึงอ่านเป็น 12345
แต่ `2 5` และ `300 83` ไม่เข้าเงื่อนไข ตกไปตามทางเดิม

`build_boxes.py` ลบคีย์เก่าของหน้าเดียวกันที่นามสกุลต่างกันก่อนเขียนคีย์ใหม่
